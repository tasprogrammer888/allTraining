## 1. Learning Objectives
เมื่อจบโมดูล ผู้เรียนสามารถ:
1. อธิบายอันตรายจากไฟฟ้า (shock / arc flash / arc blast / ไฟไหม้) และเกณฑ์กระแส mA ที่อันตรายต่อหัวใจ

5. แยก AC/DC, 1-phase/3-phase, เข้าใจ √3 และ star/delta เบื้องต้น

8. ทำ **troubleshooting** อย่างเป็นระบบ
9. ปฐมพยาบาลผู้ถูกไฟดูด (ตัดไฟ → CPR → AED)

## บทที่ 1 — ความปลอดภัยทางไฟฟ้า, LOTO และการพิสูจน์ไร้พลังงาน

### 1.1 ทำไมกระแสไฟฟ้าฆ่าคนได้ (เน้น mA ไม่ใช่ V)
สิ่งที่ฆ่าคนคือ **กระแสที่ไหลผ่านหัวใจ** ไม่ใช่แรงดันโดยตรง:

| กระแส (AC 50Hz ผ่านร่างกาย) | ผลต่อร่างกาย |
|---|---|
| ~1 mA | เริ่มรู้สึกซ่า |
| ~5 mA | เจ็บ แต่ยังสะบัดมือหลุดได้ |
| ~10–15 mA | **let-go threshold** — กล้ามเนื้อเกร็ง สะบัดมือไม่หลุด |
| ~30–100 mA | **ventricular fibrillation** หัวใจห้องล่างสั่นพลิ้ว = อันตรายถึงชีวิต |
| > 1 A | หัวใจหยุด + แผลไหม้รุนแรง |

> นี่คือเหตุผลที่ **RCD พิกัด 30 mA** เป็นมาตรฐานป้องกันคน — มันตัดก่อนถึงระดับ fibrillation

### 1.2 Arc Flash / Arc Blast
- **Arc flash** = การลัดวงจรในอากาศ ปล่อยความร้อนได้ถึง ~19,000°C (ร้อนกว่าผิวดวงอาทิตย์) → ไหม้ระดับ 3 ในเสี้ยววินาที
- **Arc blast** = แรงดันคลื่นกระแทก + โลหะหลอมเหลวกระเด็น → หูดับ, ปอดบาดเจ็บ
- เป็นเหตุผลที่ต้องมี **arc-rated clothing** และ **face shield** ไม่ใช่แค่ถุงมือ

### 1.3 ขั้นตอน LOTO (Lock-Out Tag-Out)
```
1. แจ้ง (Notify)      → บอกผู้เกี่ยวข้องว่ากำลังจะตัดไฟ
2. ปิดเครื่อง (Shut down) → ปิดตามลำดับที่ถูกต้อง
3. ตัดแหล่งจ่าย (Isolate) → สับ main breaker / ถอด disconnect
4. ล็อก (Lock)        → ใส่ padlock + hasp (กุญแจอยู่กับตัวคุณคนเดียว)
5. ติดป้าย (Tag)      → ป้ายชื่อ + วันที่ + เหตุผล
6. ปล่อยพลังงานสะสม   → discharge capacitor, ปล่อยลม, คลายสปริง
7. ตรวจสอบยืนยัน (Verify) → live-dead-live (ดู 1.4)
```

### 1.4 หลัก Live–Dead–Live (สำคัญที่สุดในโมดูลนี้)
```
[LIVE]  ทดสอบ tester กับแหล่งที่ "รู้แน่ว่ามีไฟ"   → tester อ่านได้ = tester ดี
[DEAD]  วัดจุดงานที่จะทำ                          → ต้องอ่าน 0V
[LIVE]  กลับไปทดสอบกับแหล่งมีไฟอีกครั้ง            → ยืนยัน tester ไม่เพิ่งพังตอนวัด
```
> ห้ามเชื่อ NCV (non-contact) ตัวเดียว — มันให้ ghost voltage หรือแบตหมดได้ ใช้ **two-pole tester / multimeter** ยืนยันเสมอ

### 1.5 PPE และการตรวจสภาพ
| PPE | ใช้เมื่อ |
|---|---|
| ถุงมือฉนวน + leather protector | สัมผัส/ใกล้ตัวนำมีไฟ |
| แว่นนิรภัย | ทุกงาน |
| Face shield + arc-rated suit | งานใกล้ตู้ที่อาจเกิด arc |
| รองเท้า safety | ทุกงาน |

**ตรวจถุงมือก่อนใช้ทุกครั้ง (air test):** ม้วนปลายถุงมือให้พองลม แล้วฟัง/คลำหารูรั่ว — มีรู = ทิ้ง

## บทที่ 2 — ทฤษฎีไฟฟ้าที่ใช้งานจริง

### 2.1 Water analogy
| ไฟฟ้า | เทียบกับน้ำ |
|---|---|
| แรงดัน V | แรงดันน้ำในท่อ |
| กระแส I | อัตราการไหล |
| ความต้านทาน R | ท่อแคบ/วาล์ว |

### 2.2 สูตรที่ต้องคล่อง
```
Ohm's law :  V = I × R
กำลัง     :  P = V × I   (= I²R = V²/R)
พลังงาน   :  E (kWh) = P(kW) × เวลา(h)
```
**ตัวอย่างหน้างาน:** มอเตอร์ 1-phase 230V กินกำลัง 1,500W → กระแส I = P/V = 1500/230 ≈ **6.5 A** → ต้องใช้ MCB อย่างน้อย ~10A และสายที่รับ 6.5A ได้สบาย

### 2.3 Series vs Parallel
- **Series:** กระแสเท่ากันทุกจุด, แรงดันแบ่งกัน, R รวม = R1+R2+...
- **Parallel:** แรงดันเท่ากันทุกสาขา, กระแสแบ่งกัน, 1/R = 1/R1+1/R2+...

### 2.4 คำนำหน้าหน่วยที่ใช้บ่อย
`m (milli)=10⁻³` · `k (kilo)=10³` · `M (Mega)=10⁶` · `µ (micro)=10⁻⁶`
> เจอบ่อย: 30 **m**A (RCD), 4.7 **k**Ω, 200 **M**Ω (megger), 470 **µ**F (capacitor)

## บทที่ 3 — AC vs DC และระบบ 1-phase / 3-phase

### 3.1 AC vs DC
- **DC** = ทิศทางคงที่ (แบตเตอรี่, 24V control ใน PLC — เจอใน M06)
- **AC** = สลับทิศ รูป sine wave, ไทยใช้ **50 Hz**
- ค่าที่มิเตอร์อ่าน = **RMS** (230V RMS มี peak ≈ 325V)

### 3.2 1-phase vs 3-phase และความสัมพันธ์ √3
```
ไฟบ้าน/วงจรควบคุม : 1-phase  ~230V (L-N)
ไฟมอเตอร์โรงงาน  : 3-phase  ~400V (L-L)

V(line-line) = √3 × V(line-neutral)
400V ≈ 1.732 × 230V   ✔
```

### 3.3 รหัสสีสาย (IEC / มาตรฐานปัจจุบัน)
| สาย | สี (IEC) |
|---|---|
| Line (L1/L2/L3) | น้ำตาล / ดำ / เทา |
| Neutral (N) | ฟ้า |
| Ground/PE | เขียว–เหลือง |

> ระวังของเก่าในไทยอาจใช้สีต่างออกไป — **วัดยืนยันก่อนเสมอ อย่าเชื่อสีอย่างเดียว**

### 3.4 Star (Y) vs Delta (Δ) — ปูพื้น M05/M08
- **Star (Y):** มีจุด neutral, V เฟส = V line / √3
- **Delta (Δ):** ไม่มี neutral, V เฟส = V line
- เป็นพื้นฐานของ star-delta starting ใน M05

## บทที่ 4 — เครื่องมือวัด + การอ่าน Manual/Datasheet

### 4.1 อ่าน CAT rating ก่อนใช้ (ทักษะที่คนข้ามบ่อย)
| CAT | ใช้กับ |
|---|---|
| CAT II | เต้ารับ, เครื่องใช้ปลายทาง |
| CAT III | ตู้ distribution, วงจร 3-phase ในโรงงาน |
| CAT IV | จุดเข้าไฟ, มิเตอร์การไฟฟ้า |
> งานตู้ไฟโรงงานใช้ขั้นต่ำ **CAT III 600V** — ใช้มิเตอร์ CAT ต่ำกว่างาน = เสี่ยง arc flash ระเบิดใส่หน้า

### 4.2 ตารางสรุปการวัด
| วัดอะไร | เครื่องมือ | ต่ออย่างไร | ตัดไฟก่อนไหม |
|---|---|---|---|
| แรงดัน V | multimeter | **ขนาน** กับจุดวัด | ไม่ (มีไฟถึงวัดได้) |
| กระแส (สะดวก) | **clamp meter** | หนีบ **สายเส้นเดียว** | ไม่ |
| กระแส (มิเตอร์) | multimeter (A) | **อนุกรม** | — เสี่ยง จำกัดพิกัด |
| ความต้านทาน Ω | multimeter | คร่อมตัวต้านทาน | **ตัดไฟ!** |
| Continuity | multimeter | คร่อมสาย | **ตัดไฟ!** |
| ฉนวน (MΩ) | **megger** | ขดลวด-กับ-ground | ตัดไฟ + discharge |

### 4.3 Megger — ใช้แล้วต้อง discharge
megger จ่ายแรงดันสูง (เช่น 500V) เข้าฉนวนเพื่อวัด MΩ → หลังวัดต้อง **discharge** สาย/มอเตอร์ก่อนสัมผัส มิฉะนั้นโดนไฟค้างจาก capacitance

## บทที่ 5 — อุปกรณ์ป้องกันและ Grounding

### 5.1 เปรียบเทียบอุปกรณ์ป้องกัน
| อุปกรณ์ | ป้องกัน | หลักการ |
|---|---|---|
| Fuse | กระแสเกิน/ลัดวงจร | ลวดหลอมขาด |
| MCB | กระแสเกิน/ลัดวงจร | ใช้ซ้ำได้ (รีเซ็ตได้) |
| RCD/ELCB | **ไฟรั่ว/ไฟดูด** | ตรวจกระแส L≠N (residual) |

### 5.2 MCB curve และการเลือกพิกัด
| Curve | ทริปเร็วที่ | เหมาะกับ |
|---|---|---|
| B | 3–5× In | โหลด resistive, แสงสว่าง, เต้ารับ |
| C | 5–10× In | มอเตอร์เล็ก, โหลดทั่วไปในโรงงาน |
| D | 10–20× In | มอเตอร์/หม้อแปลงที่ inrush สูง |

> **กฎเหล็ก:** พิกัด MCB ต้องไม่เกินพิกัดกระแสของสายไฟ — ไม่งั้นสายไหม้ก่อนเบรกเกอร์ทริป

### 5.3 RCD พิกัด mA
- **30 mA** → ป้องกัน *คน* (มาตรฐานวงจรที่คนสัมผัส)
- **100 / 300 mA** → ป้องกัน *ไฟไหม้* (ไม่พอป้องกันคน)

### 5.4 Neutral ≠ Ground (จุดที่เข้าใจผิดกันมาก)
- **Neutral (N):** สายนำกระแสกลับในภาวะปกติ — **มีกระแสไหล**
- **Ground/PE:** สายความปลอดภัย ปกติ **ไม่มีกระแส** มีไว้ให้กระแสรั่วไหลลงดินและทำให้เบรกเกอร์ทริป
- ในระบบ **TN-C-S** N กับ PE แยกกันที่ฝั่งโหลด — ห้ามเอามาต่อรวมที่ปลายทางเด็ดขาด

## บทที่ 6 — Troubleshooting, ปฐมพยาบาล และ Pre-work Checklist

### 6.1 Troubleshooting อย่างเป็นระบบ (ห้ามเดา-แล้ว-เปลี่ยน)
```
อาการ → ตั้งสมมติฐาน → วัดยืนยันทีละจุด → ยืนยันสาเหตุ → แก้ → ทดสอบซ้ำ
```
| อาการ | สมมติฐานที่พบบ่อย | วิธีวัดยืนยัน |
|---|---|---|
| ไฟไม่ติด | ไม่มีแรงดัน / สายขาด / ฟิวส์ขาด | วัด V ไล่จากต้นทางไปปลายทาง |
| เบรกเกอร์ทริปซ้ำ | โหลดเกิน / ลัดวงจร | clamp meter วัดกระแส, วัด Ω หาลัด |
| RCD ทริป | ไฟรั่วลง ground | แยกโหลดทีละตัวหา culprit |
| จุดร้อน/ไหม้ | จุดต่อหลวม | ตรวจ torque ขั้ว, thermal |

### 6.2 ช่วยเหลือผู้ถูกไฟดูด — ลำดับห้ามสลับ
```
1. ตัดไฟก่อน!  (อย่าแตะตัวผู้ป่วยขณะมีไฟ = จะเป็นเหยื่อรายที่ 2)
2. ประเมินสติ + การหายใจ
3. เรียกช่วยเหลือ + โทร 1669 / เบอร์ฉุกเฉินโรงงาน
4. CPR (กด 100–120 ครั้ง/นาที ลึก ~5 ซม.)
5. ใช้ AED ทันทีที่มี ทำตามเสียงสั่ง
6. ดูแลแผลไฟไหม้จาก arc — ห้ามแกะ ห้ามทายาเอง
```

### 6.3 Pre-Work Safety Checklist (ติดหน้าตู้ทุกครั้ง)
- [ ] ทำ LOTO ครบและกุญแจอยู่กับฉัน
- [ ] verify zero energy ด้วย live-dead-live แล้ว
- [ ] PPE ครบและถุงมือผ่าน air test
- [ ] discharge capacitor/พลังงานสะสมแล้ว
- [ ] ถอดเครื่องประดับโลหะ (แหวน/นาฬิกา/สร้อย)
- [ ] มี buddy / มีคนรู้ว่าฉันทำงานในตู้นี้
- [ ] มิเตอร์ CAT rating เหมาะกับงาน

## 5. ความต่อเนื่องกับโมดูลอื่น (Continuity Map)

| ปูพื้นให้ | เนื้อหาใน M00 ที่เชื่อมโยง |
