## 1. ภาพรวมและตำแหน่งในหลักสูตร

โมดูลนี้คือ "ทักษะมือ + การอ่าน/เขียนแบบ" ที่เป็นฐานของทุกโมดูลหลังจากนี้ ใน M02 ผู้เรียนจะออกแบบ relay logic — แต่ถ้าเดินสายและอ่านแบบไม่เป็น วงจรที่ออกแบบก็สร้างไม่ได้ ในโมดูล PLC (M06) และ servo/advanced wiring (M08) งานเดินสายจะซับซ้อนขึ้นมาก โมดูลนี้จึงต้องปลูก "นิสัยช่างที่ดี" ตั้งแต่ต้น: ย้ำให้แน่น ขันตาม torque อ่านแบบก่อนต่อ และทำเอกสาร as-built เสมอ

**จุดเชื่อมกับโมดูลอื่น (ไม่ซ้ำซ้อน ไม่มีช่องว่าง):**
- รับจาก **M00**: ความปลอดภัย/LOTO/multimeter — โมดูลนี้ *นำมาใช้จริง* ในขั้น dead test และ first energization ไม่สอนซ้ำทฤษฎี
- ส่งให้ **M02**: ผู้เรียนต้องเดินวงจร relay logic ที่ออกแบบเองได้ โมดูลนี้จึงเน้น start/stop + holding contact เป็น "วงจรอ้างอิง"
- *ไม่* ลงลึกเรื่อง Star-Delta/VFD (เป็นของ **M05**) และ *ไม่* แตะ PLC I/O wiring แบบเต็ม (เป็นของ **M06/M08**) — ที่นี่แค่รู้จักสัญลักษณ์ PLC I/O ในแบบเท่านั้น

## 2. Learning Objectives
เมื่อจบโมดูล ผู้เรียนสามารถ:
1. เลือกชนิด/ขนาดสายและสีสายตามมาตรฐาน + coordinate ขนาดสายกับพิกัด CB
2. ปอก/ย้ำหางปลา/ครอบ ferrule ผ่าน pull test และขัน terminal ตามค่า torque
3. ต่อ terminal block / DIN rail และจัดสายในรางตาม workmanship โรงงาน
4. อ่านสัญลักษณ์ IEC 60617 และไล่วงจรใน schematic / single-line / layout
5. ทำ wire numbering / tag numbering ตามระบบ cross-reference
6. อ่าน datasheet จริง (coil V, ratings, breaking capacity) และตั้ง overload จาก nameplate มอเตอร์
7. เขียนแบบ start/stop + power circuit พร้อม wire list และ BOM
8. ประกอบตู้จริง ทำ dead test (continuity + IR) และ first energization อย่างปลอดภัย
9. troubleshoot จุดเสียในตู้อย่างเป็นระบบด้วยแบบ + multimeter
10. ตรวจงานด้วย checklist และทำเอกสาร as-built

## 3. เนื้อหาตามบท (32 ชม.)

### บทที่ 1 — สายไฟและอุปกรณ์ปลายสาย (4 ชม.)
- ชนิดสาย: THW, VAF, VCT, NYY, control cable, shielded
- ขนาด mm2/AWG กับ ampacity และ derating (อุณหภูมิ, จำนวนสายในราง)
- **Coordination เบื้องต้น:** ขนาดสายต้องรับกระแสได้ ≥ พิกัด CB ที่ป้องกันมัน

> **ตัวอย่างกฎง่าย ๆ (รุ่นฝึก ไม่ใช่ค่าออกแบบจริง):**
>
> | CB (A) | ขนาดสายทองแดงขั้นต่ำที่ยอมรับในฝึก (mm²) |
> |---|---|
> | 16 | 1.5 |
> | 20 | 2.5 |
> | 32 | 4.0 |
>
> *เน้นหลักคิด: "CB ปกป้องสาย ไม่ใช่สายปกป้อง CB" — ถ้าสายเล็กเกิน สายจะร้อนก่อน CB ตัด*

- สีสาย (IEC): L1/L2/L3 = น้ำตาล/ดำ/เทา, N = ฟ้า, PE = เขียว-เหลือง, control AC/DC แยกสี
- ปลายสาย: ring, fork, bootlace ferrule (single/twin), pin + color code
- เครื่องมือ: stripper, ratchet crimper, ferrule crimper, **torque screwdriver**

### บทที่ 2 — ทักษะมือ: ปอก ย้ำ ครอบ + torque (5 ชม.)
- strip length ให้พอดี terminal ไม่บาดทองแดง
- เลือกขนาดหางปลา/ferrule ตาม color code
- ย้ำด้วย ratchet crimper → ตรวจ crimp profile → **pull test**
- ห้ามบัดกรีปลายสายอ่อนเข้า screw terminal (เกิด cold flow หลวมภายหลัง)
- twin ferrule เมื่อต่อ 2 สายเข้าจุดเดียว
- **ค่า torque:** อ่านจาก datasheet, ขันด้วย torque screwdriver — หลวม = ร้อน = ไฟไหม้

### บทที่ 3 — terminal block, DIN rail, wire duct (4 ชม.)
- terminal: screw, push-in, feed-through, ground, fuse type
- ติดตั้งบน DIN rail + end stop + marker
- wire duct: bend radius, **fill ratio ≤ ~60%**, แยก power/control/signal
- cable tie, spiral wrap, service loop
- workmanship: ตรง สวย ซ่อมง่าย

### บทที่ 4 — อ่านแบบ + IEC 60617 + datasheet (5 ชม.)
- ประเภทแบบ: single-line, power, control (schematic), layout/GA, connection diagram
- สัญลักษณ์ IEC 60617 หลัก ๆ:

| อุปกรณ์ | Designation | สัญลักษณ์ (อธิบาย) |
|---|---|---|
| Circuit breaker (MCB) | Q / F | สี่เหลี่ยมพร้อมเครื่องหมายตัด |
| Contactor | KM | คอยล์ + main contacts |
| Overload relay | F | ขดความร้อน + NC aux contact |
| Push button (NO) | S | หน้าสัมผัสเปิดปกติ |
| Push button (NC) | S | หน้าสัมผัสปิดปกติ |
| Pilot lamp | H | วงกลม + กากบาท |
| Motor 3φ | M | วงกลม M3~ |

- การอ่าน contact NO/NC + coil, ไล่ ladder rung บน→ล่าง ซ้าย→ขวา
- cross-reference: coil ที่ rung หนึ่งกับ contact ที่ rung อื่น (page/column ref)
- **อ่าน datasheet จริง:** coil voltage, AC1/AC3 rating, breaking capacity (kA), overload setting range

### บทที่ 5 — wire numbering, tag, documentation (4 ชม.)
- wire numbering: potential-based vs source-destination
- tag terminal: X1:1, X1:2 …
- wire list / from-to list + terminal plan
- wire marker / ferrule printer ต้องตรงแบบ
- document set: cover + BOM + schematic + layout + wire list + as-built
- คติประจำโมดูล: **"ไม่มีแบบ = ซ่อมไม่ได้"**

### บทที่ 6 — เขียนแบบเบื้องต้น (4 ชม.)
- title block, grid, แบ่งหน้า power/control
- power: main breaker → contactor → overload → motor
- control: start/stop + holding contact (self-hold)
- เพิ่ม pilot lamp, E-stop (NC fail-safe), interlock
- CAD ไฟฟ้า vs เขียนมือ + สร้าง BOM จากแบบ

**ตัวอย่าง Power Circuit (ASCII):**
```
   L1  L2  L3
    |   |   |
   [ Q1 MCB 3P ]
    |   |   |
   [ KM1 main contacts ]
    |   |   |
   [ F2 overload ]
    |   |   |
    +---+---+---  --> M 3~ (มอเตอร์)
                    PE --> ตัวมอเตอร์
```

**ตัวอย่าง Control Circuit — Start/Stop + Self-hold (ladder, 24VDC):**
```
 L(+)                                              N(-)
  |                                                 |
  |--[ S0 E-stop NC ]--[ F2 OL NC ]--+--[ S1 Stop NC ]--+--( KM1 coil )--|
  |                                  |                  |
  |                          [ S2 Start NO ]            |
  |                                  |                  |
  |                          [ KM1 aux NO ]-------------+   <-- holding contact
  |
  |--[ KM1 aux NO ]--( H1 RUN lamp )--
```
- กด S2 (Start) → KM1 มีไฟ → KM1 aux NO ปิด → ค้างไว้ (self-hold)
- กด S1 (Stop) หรือ E-stop หรือ overload trip → ตัดวงจร → KM1 ปลด
- **E-stop เป็น NC fail-safe:** สายขาด = วงจรเปิด = หยุด (ปลอดภัย)

### บทที่ 7 — ประกอบตู้ + first energization + troubleshooting (6 ชม.)
- อ่านแบบ → วาง layout บน back plate
- ติดตั้ง DIN rail, duct, อุปกรณ์ + **ตั้ง overload จาก FLA บน nameplate**
- เดินสาย power + control + wire marker + **ขัน torque**
- ต่อ ground/bonding + dress สาย
- **Dead test → Live test → Troubleshooting** (ดู checklist ด้านล่าง)

## 4. การตั้งค่า Overload จาก Nameplate (ทักษะที่ขาดไม่ได้)

มอเตอร์มี nameplate บอก **FLA (Full Load Ampere)** เช่น `0.75 kW, 400V, 1.8A`
1. อ่านค่า FLA จาก nameplate (ที่แรงดันที่ใช้จริง)
2. ตั้ง dial ของ overload relay ที่ค่า FLA (หรือ ×1.0–1.15 ตาม service factor และคู่มือ)
3. ตรวจว่าค่าอยู่ใน setting range ของ overload (จาก datasheet)

> ตั้งสูงเกิน = ไม่ป้องกัน (มอเตอร์ไหม้) | ตั้งต่ำเกิน = trip บ่อย (สายการผลิตหยุด)

### รายละเอียด Lab 1.7 — Troubleshooting Drill (เพิ่มใหม่)
ครูใส่ fault 4–6 จุดในตู้ (หรือสลับตู้กับเพื่อน) เช่น:
- สายหลุด / ต่อผิด terminal
- overload ตั้งต่ำเกินจน trip
- สาย control ขาดภายใน (ดูปกติแต่ไม่ต่อ)
- coil voltage ผิด (เช่น ใส่ coil 220V ในระบบ 24V)

**วิธีคิดที่ฝึก:** อาการ → สมมุติฐาน → วัดยืนยัน (multimeter + แบบ) → แก้ → ทดสอบซ้ำ
ทำในสภาวะปลอดภัย: **dead test ก่อนเปิดฝา** เสมอ

## 6. Checklists สำหรับสอน/ส่งงาน

### Dead Test Checklist (ก่อนจ่ายไฟ — ทำกับไฟดับเท่านั้น)
- [ ] Visual: ทุกสายเข้า terminal ถูกตาม wire list, ไม่มีเส้นทองแดงโผล่
- [ ] ทุกขั้วขันตาม torque (สุ่มตรวจด้วย torque screwdriver)
- [ ] Continuity: ไล่ point-to-point ตาม from-to list ทุกเส้น
- [ ] PE/Ground continuity ครบทุกอุปกรณ์ (อ่านค่าใกล้ 0 Ω)
- [ ] Insulation (IR) test: L-L, L-N, L-PE ≥ เกณฑ์ (เช่น ≥ 1 MΩ ในงานฝึก)
- [ ] overload ตั้งตรง FLA, coil voltage ตรงกับระบบ

### First Energization Checklist (Live — ทำกับครู ใช้ PPE/LOTO)
- [ ] สวม PPE, มีผ้ายางปูพื้น, รู้ตำแหน่ง E-stop/main breaker
- [ ] ปลด LOTO ตามขั้นตอน, แจ้งทุกคนก่อนจ่ายไฟ
- [ ] จ่าย **control circuit ก่อน** (24VDC) → ทดสอบ start/stop/E-stop/lamp โดยยังไม่ต่อมอเตอร์
- [ ] เมื่อ control ผ่าน → จ่าย **power** → ทดสอบมอเตอร์หมุน ทิศถูก
- [ ] วัดกระแสขณะรัน เทียบ FLA, ฟัง/ดมหาความผิดปกติ
- [ ] บันทึกผล + เซ็นรับรอง

### Workmanship Checklist
- [ ] สายตรง เป็นระเบียบ ใน duct ไม่เกิน fill ratio
- [ ] แยก power/control/signal, bend radius เหมาะสม
- [ ] wire marker ตรงแบบทุกเส้น, มี service loop
- [ ] as-built ตรงกับงานจริง (แก้แบบให้ตรงถ้าหน้างานเปลี่ยน)

## 7. Common Mistakes & Safety (สิ่งที่เห็นบ่อยหน้างาน)
1. ปอกสายบาดทองแดง → สายร้อน → ตั้ง stripper ให้ถูก
2. ย้ำหางปลาด้วยคีมธรรมดา/ไม่แน่น → **สาเหตุอันดับต้นของไฟไหม้ในตู้** → ratchet + pull test
3. ขนาด ferrule/หางปลาไม่ตรงสาย → เทียบ color code + mm²
4. บัดกรีปลายสายอ่อนเข้า screw terminal → ห้าม (cold flow) → ใช้ ferrule
5. ขันแน่น/หลวมเกินไม่ดู torque → ใช้ torque screwdriver
6. สายเล็กกว่าพิกัด CB → coordinate ขนาดสาย/CB เสมอ
7. duct แน่นเกิน fill ratio / power+signal รวมกัน → noise + ร้อน
8. ลืมต่อ PE หรือต่อไม่ครบ → อันตรายถึงชีวิต → ตรวจ continuity PE
9. overload ไม่ตรง FLA → ตั้งตาม nameplate
10. E-stop เป็น NO / ไม่ fail-safe → ใช้ NC fail-safe
11. จ่ายไฟครั้งแรกโดยไม่ dead test → ทำ dead test ผ่านก่อนเสมอ จ่าย control ก่อน power
12. เปิดฝาตู้มีไฟโดยไม่ LOTO → ตัดไฟ ล็อก แขวนป้าย **verify dead** ก่อน (ตาม M00)

## 8. Equipment & Software (สรุป)

- ปลายสาย: ring/fork, ferrule single/twin, pin + color code
- เครื่องมือ: stripper, ratchet crimper, ferrule crimper, cutter, ไขควงชุด insulated, **torque screwdriver**

- back plate, cable tie, spiral wrap, wire marker, ferrule printer
- อุปกรณ์ตู้: MCB, contactor (เช่น Mitsubishi MS-T), thermal overload, push button, E-stop, pilot lamp, 24VDC PSU
- มอเตอร์ 3φ เล็ก + nameplate อ่าน FLA ได้

- PPE + **LOTO kit** + ผ้ายางปูพื้น
- CAD ไฟฟ้า (EPLAN Education / AutoCAD Electrical / ทางเลือกฟรี) หรือกระดาษกริด
- เอกสาร: IEC 60617 chart, **datasheet จริง** ของ contactor/overload/MCB, แบบตัวอย่าง, checklist ทุกชุด
