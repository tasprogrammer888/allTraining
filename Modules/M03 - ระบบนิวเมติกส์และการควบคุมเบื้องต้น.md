## สิ่งที่แก้/ยกระดับจากร่างเดิม (สรุปให้ผู้สอน)

1. **Lubricator (L) ใน FRL** — ร่างเดิมสอนใช้ lubricator เป็นปกติ ซึ่ง *ผิดยุค*: วาล์ว/cylinder/sensor สมัยใหม่เป็น non-lube และน้ำมันทำให้ sensor เสีย แก้เป็นสอน **FR เป็นหลัก** ใส่ L เฉพาะที่ datasheet กำหนด
2. **reed switch "24VDC PNP"** — ร่างเดิมเขียนผิดเชิงเทคนิค: reed switch แท้คือ **2-wire dry contact** ส่วน 3-wire PNP คือ solid-state (Hall/MR) เพิ่มหัวข้อแยกสองชนิด + Lab อ่าน datasheet จริง
3. **signal overlap ของ A+B+A-B-** — ร่างเดิมบอกว่าลำดับนี้มี overlap ต้อง cascade ซึ่ง *ไม่ถูก*: A+B+A-B- ต่อด้วย sensor interlock ตรง ๆ ได้ overlap เกิดในลำดับเช่น A+A-B+B- แก้ให้ถูกและยังสอนแนวคิด cascade
4. **เพิ่ม flyback/surge diode** ให้เป็นหัวข้อชัดพร้อมเรื่องขั้ว (กลับขั้ว = short)
5. **เพิ่ม meter-out สำหรับงานยกโหลด** เป็นจุดเน้น (ความปลอดภัย run-away)
6. **เพิ่ม troubleshooting drill** ใน Lab 6 และ flow chart แก้ปัญหา
7. เติม **safety gate** และ assessment ที่วัด competency จริง

## จุดความรู้สำคัญ (เน้นที่หน้างานพลาดบ่อย)

### FR vs FRL — อย่าใส่ Lubricator พร่ำเพรื่อ
- ระบบ training และเครื่องสมัยใหม่ส่วนใหญ่ใช้ **non-lube** วาล์วมี seal ที่หล่อลื่นในตัว
- ใส่น้ำมันเข้าไป -> เคลือบ reed/Hall sensor และ seal วาล์วบางรุ่นจนเสีย
- กฎ: ใส่ L **เฉพาะเมื่อ datasheet ของ actuator ระบุ** เท่านั้น

### Flow Control — งานยกต้องใช้ meter-out
```
meter-in : หรี่ลม "ขาเข้า"   -> โหลดแนวยก = กระตุก/run-away ตอนรับโหลด (อันตราย)
meter-out: หรี่ลม "ขาออก"    -> สร้าง back-pressure คุมโหลดนิ่ง  <-- ใช้กับงานยก/ดัน
```
หลักจำง่าย: **"คุมที่ทางออก ของไหลที่ดันโหลด"**

### Sensor บนกระบอก — reed vs solid-state (ห้ามต่อมั่ว)
| | Reed switch | Solid-state (Hall/MR) PNP |
|---|---|---|
| สายไฟ | 2-wire (dry contact) | 3-wire |
| การต่อ | อนุกรมเหมือนสวิตช์ | BN=+24V, BU=0V, BK=signal |
| ข้อจำกัด | contact สึก, ไวงานเชื่อม, ต้องมี contact protection | ทนรอบสูง, ไม่มีหน้าสัมผัสกล |
| ใช้เมื่อ | งานรอบต่ำ ราคาถูก | งาน automation รอบสูง (Pick & Place) |

> ร่างเดิมเขียน "reed switch 24VDC PNP" = ผิด ต้องแยกสองชนิดให้ชัด แล้วอ่าน wiring จาก datasheet ทุกครั้ง

### Electro-pneumatics — flyback diode บนคอยล์ (วิกฤต)
```
        +24V ──┬────────────── (relay contact) ──┐
               │                                  │
            ▲(cathode/แถบ)                     [ SOLENOID ]
            │  diode 1N4007 คร่อมคอยล์            COIL
            │(anode)                              │
        0V ─┴──────────────────────────────────┘
```
- **แถบขาว (cathode) ไปด้าน +24V** เสมอ
- ไม่ใส่ -> inductive spike กัดหน้าสัมผัส relay / ทำลาย transistor PLC output ใน M06
- **กลับขั้ว = ลัดวงจร** (เป็นจุดที่ผู้เรียนพังบ่อยมาก สาธิตด้วยการวัด)

### Mono-stable vs Bi-stable — เลือกตาม fail-safe
- **single solenoid (mono-stable):** ไฟดับ -> spring ดันกลับตำแหน่งเริ่ม (fail-safe)
- **double solenoid (memory):** ไฟดับ -> **ค้างตำแหน่งเดิม** (อาจอันตราย เช่น gripper ค้างหนีบ)
- ห้ามจ่ายสอง coil พร้อมกัน — สั่งแบบ pulse set/reset + interlock

### Sequential — เข้าใจ signal overlap ให้ถูก
**A+ B+ A- B-** ต่อด้วย sensor interlock ตรง ๆ ได้ (ลำดับเริ่มต้นที่ดี):
```
START ─► A+ ──(a1)──► B+ ──(b1)──► A- ──(a0)──► B- ──(b0)──► จบรอบ
```
**signal overlap เกิดเมื่อ** sensor ตัวเดียวถูกใช้สั่งทั้ง set และ reset ของวาล์วเดียวกันในจังหวะทับซ้อน เช่นลำดับ **A+ A- B+ B-** (a1 สั่ง A- แต่ a1 ยังอยู่ตอน A+...) -> ต้องแก้ด้วย **cascade / group method** (สอนเชิงหลักการในระดับนี้)

## Troubleshooting Flow (สอนใน Lab 6 — ใช้ต่อใน M12)

```
อาการ: cylinder ไม่ขยับ
 ├─ มีลมถึงวาล์วไหม? (ดูเกจ)            ── ไม่มี ─► เช็ค FR / shut-off / สายลม
 ├─ solenoid มีไฟไหม? (วัด V ที่ coil)  ── ไม่มี ─► เช็ค relay / wiring / fuse
 ├─ ได้ยิน click วาล์วสลับไหม?          ── ไม่ ──► coil เสีย / วาล์วติด
 ├─ สาย A/B ต่อสลับไหม?                 ── ใช่ ─► สลับสายลมให้ถูก port
 └─ flow control หรี่ค้างไหม?           ── ใช่ ─► คลายวาล์ว

อาการ: ขยับช้า/กระตุก ─► flow control / ลมไม่พอ / friction / meter-in กับโหลด
อาการ: ลำดับข้าม/ค้าง ─► sensor ตำแหน่งเพี้ยน / สาย sensor สลับ / interlock ผิด
```
