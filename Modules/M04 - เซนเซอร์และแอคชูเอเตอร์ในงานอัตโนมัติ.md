## ภาพรวมและตำแหน่งของโมดูลในหลักสูตร

โมดูลนี้เป็น "สะพาน" ระหว่างโลกของวงจรรีเลย์ (M02) กับโลกของ PLC (M06) ผู้เรียนต้องต่อ "ตา/มือ" ของเครื่องให้เป็นก่อนจะไปเขียน "สมอง"

**ความต่อเนื่อง (ไม่ซ้ำ ไม่มีช่องว่าง):**
- รับช่วงจาก **M03**: reed switch บนกระบอกลมได้ถูกแนะนำในบริบทนิวเมติกส์แล้ว ที่นี่เจาะลึกการต่อทางไฟฟ้า (2-wire, residual current) ไม่สอนนิวเมติกส์ซ้ำ
- รับช่วงจาก **M02**: แนวคิด NO/NC/COM/common มาจากวงจรรีเลย์ ที่นี่ขยายสู่ sink/source ของ PLC
- **ไม่ก้าวก่าย M06**: โมดูลนี้ "ไม่สอนเขียน ladder" ผู้เรียนใช้แต่ GX Works3 ในโหมด *monitor* และ *force output* + โหลดโปรแกรมตัวอย่างที่ครูเตรียมให้ (HSC, analog read) เพื่อยืนยันการต่อสายเท่านั้น การเขียนโปรแกรมจริงอยู่ใน M06
- **เกริ่นสู่ M05/M08**: PWM/analog output ถูกแตะเพียงเพื่อปูทางไป servo/inverter

## บทที่ 5 (เจาะลึก): NPN vs PNP และ S/S terminal ของ FX5U

นี่คือ "หัวใจ" ของโมดูลและจุดที่ช่างหน้างานพลาดบ่อยที่สุด

**รหัสสีสาย (IEC) — ต้องยืนยันกับ datasheet เสมอ:**

| สี | หน้าที่ |
|---|---|
| Brown | +24V |
| Blue | 0V |
| Black | สัญญาณ output |
| White | output ที่ 2 (เช่น NC หรือ output อีกชนิด แล้วแต่รุ่น) |

**ความต่างหลัก:**
- **NPN (sinking):** ตอน active เซนเซอร์ดึงสาย black ลงไปที่ 0V → กระแส *ไหลเข้า* เซนเซอร์
- **PNP (sourcing):** ตอน active เซนเซอร์ดัน black ขึ้นไปที่ +24V → กระแส *ไหลออก* จากเซนเซอร์

**FX5U S/S Truth Table (จำให้ขึ้นใจ):**

| ต่อ S/S เข้ากับ | Input เป็นแบบ | ต้องใช้เซนเซอร์ |
|---|---|---|
| **0V** | Source input | **PNP** |
| **+24V** | Sink input | **NPN** |

> กฎจำง่าย: *S/S ต่อ 0V ↔ PNP / S/S ต่อ 24V ↔ NPN* (สลับฝั่งกันเสมอ)

**ตัวอย่าง wiring — PNP sensor เข้า FX5U (S/S = 0V):**
```
 24VDC(+) ──┬─────────────── Brown (sensor +)
            │
            │   Sensor(PNP) Black ──────► X0
            │
 24VDC(0V) ─┴── Blue (sensor 0V)
            └──────────────────────────► S/S
```

**ตัวอย่าง wiring — NPN sensor เข้า FX5U (S/S = +24V):**
```
 24VDC(+) ──┬── Brown (sensor +)
            └──────────────────────────► S/S
 24VDC(0V) ─┬── Blue (sensor 0V)
            │
            │   Sensor(NPN) Black ──────► X0
```

**พิสูจน์ NPN/PNP ด้วยมัลติมิเตอร์ (โหมด VDC):**
1. จ่ายไฟ brown(+24)/blue(0V) ให้เซนเซอร์
2. ทำให้เซนเซอร์ active (เอา target เข้าใกล้)
3. วัดแรงดัน black เทียบ blue(0V):
   - อ่านได้ ~24V → **PNP** (จ่าย +24V ออก)
   - อ่านได้ ~0V → ลองวัด black เทียบ brown(+24V) ได้ ~0V → **NPN** (ดึงลง 0V)

## บทที่ 8 (เจาะลึก): การขับ actuator และ flyback diode

**Solenoid/relay coil = inductive load** เมื่อตัดไฟจะเกิด voltage spike สูงมาก (หลายร้อยโวลต์) ทำลาย transistor output ของ PLC

**DC load → flyback (freewheel) diode คร่อม coil:**
```
        Y0 ──────────┬──── (+ coil)
                      │
                  ▲ cathode  (แถบขีดของ diode อยู่ฝั่ง +)
                  │   diode (เช่น 1N4007)
                  ▼ anode
                      │
        COM(0V) ──────┴──── (- coil)
```
> ขั้วสำคัญมาก: **cathode (แถบ) → ฝั่ง +** ถ้าต่อกลับ = diode ลัดวงจร โหลดไม่ทำงานและ diode พัง

**AC load → RC snubber** (ใช้ diode ไม่ได้กับ AC) หรือ varistor คร่อม contact

**Interposing relay** ใช้เมื่อ:
- โหลดเกิน rating ต่อจุดของ PLC
- ต้องขับ AC load จาก transistor output (DC) ของ PLC
- ต้องการแยก (isolate) วงจร field ออกจาก PLC

## บทที่ 7 (เจาะลึก): analog 4-20mA และ scaling

**ทำไม 4-20mA ดีกว่า 0-10V:**

| ประเด็น | 4-20mA | 0-10V |
|---|---|---|
| Wire-break detection | ได้ (<4mA = สายขาด) | ไม่ได้ (0V กำกวม) |
| ทน noise / สายยาว | ดีมาก | แย่ลงตามความยาว |
| Voltage drop ในสาย | ไม่กระทบ (loop current คงที่) | กระทบ |
| การต่อ | 2/3/4-wire | ง่ายกว่าเล็กน้อย |

**Linear scaling (ตัวอย่าง pressure 0-100 bar, raw 0-32000 ที่ FX5U analog):**
```
ค่าจริง (bar) = (Raw - Raw_min) × (Eng_max - Eng_min) / (Raw_max - Raw_min) + Eng_min
              = (Raw - 6400) × 100 / (32000 - 6400) + 0      ← เริ่มที่ 4mA = 6400 raw
```
> หมายเหตุ: ค่า raw ขึ้นกับการตั้ง analog ของ FX5U (ตรวจจากคู่มือจริง) แล้วแมป 4mA→ค่าต่ำสุด, 20mA→ค่าสูงสุด

## Power-On Safety Checklist (ใช้ทุกแล็บ)

- [ ] ตัดไฟอยู่ขณะต่อสาย (LOTO ตาม M00)
- [ ] ตรวจขั้ว 24V(+) / 0V ไม่สลับ
- [ ] วัด continuity: ไม่มี short ระหว่าง + และ - (ก่อนจ่ายไฟ)
- [ ] มี fuse อนุกรมในลูปทดลอง
- [ ] polarity ของเซนเซอร์ (brown/blue) ถูกต้องตาม datasheet
- [ ] ขั้ว flyback diode ถูกต้อง (ถ้ามีโหลด inductive)
- [ ] S/S ต่อถูกตาม truth table (NPN/PNP)
- [ ] ferrule/wire tag ครบ สายไม่หลวม
- [ ] ครูเซ็นอนุมัติ → จ่ายไฟทีละกลุ่ม

## ขั้นตอน Troubleshooting อย่างเป็นระบบ (Lab 8)

```
1. ดู LED  ───► เซนเซอร์ติด? input X ติดบน PLC?
2. วัดแรงดันที่ขั้ว ───► มี 24V ที่ brown? มีสัญญาณที่ black?
3. ไล่ field → terminal → S/S/common → PLC input
4. แยกชั้น: bench-test เซนเซอร์เดี่ยวก่อน → แล้วค่อยโทษสาย/PLC
5. แก้ → ทดสอบซ้ำ → บันทึก
```

**Fault ยอดฮิตและอาการ:**

| Fault | อาการ |
|---|---|
| สลับ NPN/PNP (S/S ผิด) | input ทั้งบล็อกไม่ติด / ติดกลับด้าน |
| ลืม/หลุด common (S/S) | กลุ่ม input ตายทั้งกลุ่ม |
| สายหลวม / wire-break | input กระพริบ / ค่า analog ตก |
| Short | fuse ขาด / power dip |
| ลืม flyback diode | output transistor พังหลังตัดโหลด |
| Ground loop / shield 2 ด้าน | ค่า analog/encoder แกว่ง |

## ข้อผิดพลาดที่พบบ่อย & ความปลอดภัย (สรุป)

ดูรายการเต็มในฟิลด์ `common_mistakes_safety` — เน้น 3 ข้อที่ทำของพังจริง:
1. **ต่อกลับขั้ว brown/blue → เซนเซอร์พังถาวร** (ต้องมี fuse + ตรวจ polarity)
2. **flyback diode กลับขั้ว/ไม่มี → output PLC พัง**
3. **วัด 4-20mA แบบขนานแทนอนุกรม → ลัดลูป/อ่านผิด**
