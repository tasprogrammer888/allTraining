# คู่มือการจัดสอน (Delivery & Instructor Guide)
## หลักสูตรช่างไฟฟ้า–ซ่อมบำรุงระบบอัตโนมัติ (PLC / HMI / Servo / Robot / Communication)

> เอกสารนี้สำหรับ "ผู้สอน / ผู้จัดอบรม / ผู้ดูแลแล็บ" ใช้เป็นแนวทางส่งมอบหลักสูตร เป้าหมายคือพาคนที่ "ไม่มีพื้นฐานเลย" ไปสู่ "ทำงานจริงได้" โดยยึดหลัก **เรียนด้วยการลงมือทำ (hands-on) เป็นแกนกลาง** และ **ความปลอดภัยมาก่อนเสมอ (Safety First)**

---

## 1. ปรัชญาการสอนและรูปแบบการจัดสอน (Delivery Mode)

> **จุดเปลี่ยนสำคัญของหลักสูตร (ฉบับปรับปรุง):** หลักสูตรนี้ให้บริการแบบ **ออนไลน์เป็นแกนหลัก** โดยมีบริการ **เรียนออฟไลน์ (มีค่าใช้จ่าย)** และ **ออกไปสอนถึงต่างจังหวัด** เสริม สิ่งที่ทำให้ "ออนไลน์" ยังพาไปถึง "ทำงานจริงได้" คือ **Remote Lab — ผู้เรียนต่อออนไลน์เข้ามาใช้เครื่องจริงฟรี ดูผ่านกล้อง และเขียนโปรแกรม PLC สั่งเครื่องจักรจริงได้** (รายละเอียดระบบใน §1.3 และเอกสาร A)

### 1.1 หลักการหลัก 6 ข้อ
1. **Hands-on first (บนของจริงเสมอ ไม่ว่าอยู่ที่ไหน)** — ทุกแนวคิดต้องจบที่ "ต่อจริง / เขียนจริง / วัดจริง" งานเขียนโปรแกรมและ commissioning logic ทำบน **hardware จริงผ่าน Remote Lab** ได้ ส่วนงานมือ (wiring/crimp/LOTO/วัด) ต้องอยู่หน้าเครื่องจริง
2. **Safety is non-negotiable** — LOTO, live-dead-live, pre-power-on check เป็น "ประตูผ่าน" ทุก lab ที่มีไฟ/ลม/การเคลื่อนที่ — และเมื่อ **คุมเครื่องจริงทางไกล** ต้องมี safety layer เพิ่ม (ดู §1.6)
3. **See it → Do it → Teach it** — ผู้สอนสาธิต → ผู้เรียนทำตาม → ผู้เรียนอธิบาย/สอนเพื่อน (ทำได้ทั้งในห้องและผ่าน screen-share / Remote Lab)
4. **Real documents** — ใช้ datasheet / manual / schematic ของจริง (Mitsubishi, KUKA, Omron ฯลฯ) ตั้งแต่วันแรก ไม่ใช้เอกสารปลอม
5. **Build toward Capstone** — ทุกโมดูลคือ "ชิ้นส่วน" ของเครื่อง Pick & Place ที่จะประกอบใน M12
6. **Real hardware, not just simulator** — simulator ใช้ฝึกซ้ำ/ลองผิดปลอดภัยได้ แต่ทุกทักษะต้อง "ปิดงานบนของจริง" — ผู้เรียนออนไลน์ใช้ **Remote Lab (PLC/HMI/servo/robot จริง)** เป็นตัวปิดงาน ไม่ใช่จบแค่ simulator

### 1.2 สี่รูปแบบการจัดสอน (Delivery Modes)

| โหมด | รูปแบบ | เหมาะกับ | ตำแหน่งราคา |
|---|---|---|---|
| **① Online (แกนหลัก)** | เรียนสด (live) ผ่านวิดีโอคอล + เนื้อหา self-paced + **Remote Lab เขียน/รันบนเครื่องจริง (ฟรี)** | ทฤษฎี + โมดูลเขียนโปรแกรม (M06–M13), ช่างที่มีทักษะมืออยู่แล้ว (persona B/C/D), คนต่างจังหวัดที่มาศูนย์ไม่สะดวก | ถูกที่สุด / สเกลได้ |
| **② Offline / In-person (พรีเมียม)** | มาที่ศูนย์ ลงมือกับของจริงเต็มรูปแบบ | โมดูลทักษะมือ (wiring, crimp, LOTO, panel, ต่อ servo/robot จริง — M00–M05 + งาน wiring ใน M08/M09), persona A (มือใหม่) | สูงสุด (มี station + วัสดุ + PPE) |
| **③ On-site / ต่างจังหวัด** | ทีมผู้สอน + ชุดอุปกรณ์เคลื่อนที่ เดินทางไปสอนถึงที่ | corporate/กลุ่ม/สถาบันในต่างจังหวัด ที่อยากเทรนทีมโดยไม่ต้องส่งคนเข้าเมือง | เหมาวัน + ค่าเดินทาง |
| **④ Hybrid** | Online (ทฤษฎี+โปรแกรม ผ่าน Remote Lab) + มาศูนย์เป็น block สั้นทำงานมือ | คนที่อยากได้ทั้งความยืดหยุ่นออนไลน์และทักษะมือครบ (โดยเฉพาะ persona A ที่อยู่ไกล) | กลาง |

**ข้อสรุปการตัดสินใจ:**
- **Online = แกนการเข้าถึง (reach):** เรียนที่ไหนก็ได้ ต้นทุนต่อหัวต่ำ และได้แตะเครื่องจริงผ่าน Remote Lab
- **Offline = พรีเมียมสำหรับ "ทักษะมือ"** ที่ออนไลน์แทนไม่ได้ (จับ ปอก ย้ำ วัด ทำ LOTO ประกอบตู้) — จึงมีราคา และเป็นเหตุผลที่คนยอมจ่ายเพื่อมาเรียนที่ศูนย์
- **On-site = ช่องขยายสู่ต่างจังหวัด/corporate** — ยกหลักสูตรและชุดอุปกรณ์ไปหาลูกค้าถึงที่
- เป้าหมาย "ทำงานจริงได้" ยังอยู่ครบ เพราะทุกโหมด **ปิดงานบน hardware จริง** (ที่ศูนย์ หรือผ่าน Remote Lab)

> **หมายเหตุการเปลี่ยนแปลง:** ฉบับก่อนระบุ "Online เต็มรูปแบบ = ไม่แนะนำ" เพราะสมมติว่าออนไลน์ = simulator/วิดีโอเท่านั้น เมื่อมี **Remote Lab (เครื่องจริงต่อทางไกล + กล้อง)** ข้อจำกัดนั้นหมดไปสำหรับงานเขียนโปรแกรม/commissioning ออนไลน์จึงเป็นแกนหลักได้ คงเหลือเพียง "ทักษะมือ" ที่ยังต้องอยู่หน้าเครื่อง (โหมด ②/④)

### 1.3 Remote Lab — เข้าถึงเครื่องจริงทางไกล (หัวใจของโมเดลออนไลน์)

**แนวคิด:** ศูนย์ตั้ง rig เครื่องจริง (FX5U + GOT + MELSERVO + inverter + conveyor/Pick&Place + KUKA) ต่อเครือข่ายไว้ ผู้เรียนออนไลน์ **จองเวลา → รีโมตเข้ามาเขียนโปรแกรม → download ลง PLC จริง → ดูเครื่องตอบสนองสดผ่านกล้องหลายมุม** เสมือนยืนอยู่หน้าเครื่อง (สเปกระบบดูเอกสาร A หมวด Remote Lab)

**ผู้เรียนทำอะไรได้บ้างผ่าน Remote Lab:**
- เขียน ladder/SFC ใน GX Works3 → download → online monitor บน **FX5U จริง**
- ออกแบบจอ GOT → transfer → กดใช้งานบน **GOT จริง** เห็นผลผ่านกล้อง
- สั่ง servo positioning (JOG/Homing/DRVA/DRVI) เห็นแกน **ballscrew จริง** วิ่งผ่านกล้อง
- รันโปรแกรม KRL ที่เขียน offline บน **หุ่น KUKA จริง** (มี TA คุมความปลอดภัยหน้างาน)
- ตั้งค่า Modbus/Ethernet ให้ PLC ↔ inverter ↔ HMI จริงคุยกัน
- ฝึก troubleshooting: ผู้สอน inject fault ทางไกล ผู้เรียนไล่หาผ่าน online monitor + กล้อง

**สิ่งที่ Remote Lab แทนไม่ได้ (ต้องโหมด ②/④ หน้าเครื่อง):**
- งานมือ: ปอกสาย ย้ำหางปลา/ferrule จัดสายในตู้ ขัน torque
- LOTO / live-dead-live / วัดด้วย multimeter–megger ด้วยมือตัวเอง
- ประกอบตู้ (panel building), ต่อ wiring servo/robot/pneumatic จริง
- ความรู้สึก "สัมผัส" ของงานไฟ (แรงย้ำ ความแน่น terminal)

> เส้นแบ่งจำง่าย: **"เขียน / สั่ง / ดู" ทำได้ทางไกล — "จับ / ต่อ / วัด" ต้องหน้าเครื่อง**

### 1.5 การดำเนินการสอนออนไลน์ (Online Delivery Operations)

**เครื่องมือ:**
- **Video conferencing** (Zoom/Google Meet/MS Teams) — เรียนสด + breakout room งานกลุ่ม
- **LMS / คลังเนื้อหา** — วิดีโอ self-paced, ใบงาน, ข้อสอบ, ส่งงาน (Google Classroom / Moodle / LMS เชิงพาณิชย์)
- **Remote Lab portal** — ระบบจองเวลา rig + remote access เข้าเครื่องจริง (ดู A หมวด Remote Lab)
- **กล้องหลายมุมต่อ rig** — มุมรวม, มุมใกล้การเคลื่อนที่, มุมจอ HMI/ไฟแสดงสถานะ
- **Screen-share สองทาง** — ผู้สอนดู/คุมจอผู้เรียนเพื่อ debug ได้

**รูปแบบคาบเรียนสดออนไลน์ (แนะนำ ~2–3 ชม./คาบ):**
1. บรรยายสั้น + สาธิตบนเครื่องจริง (≤20–25 นาที) — กฎ 20–25 นาทีเหมือนเดิม
2. ผู้เรียนลงมือใน simulator/Remote Lab พร้อมกัน ผู้สอนเดินสาย (screen-share) รายคน
3. Checkpoint: ผู้เรียนโชว์ผลบนเครื่องจริงผ่านกล้อง/แชร์จอ
4. สรุป + exit ticket + มอบหมายงาน Remote Lab นอกเวลา (จองรอบ)

**บทบาททีมออนไลน์:**
- **Lead instructor** — บรรยาย/สาธิต/ตรวจงาน
- **Online TA / Lab supervisor** — ตอบแชท, ช่วย debug รายคน, **และคุมความปลอดภัยหน้า rig ระหว่างมีการรันเครื่องจริงทางไกล** (สำคัญมากในโมดูล servo/robot/capstone)
- อัตราส่วนออนไลน์แนะนำ **1 : 8–12** สำหรับงานเขียนโปรแกรม (ดู §3)

**การจัดคิว Remote Lab:** rig มีจำกัด → ใช้ระบบจอง slot (เช่น 60–90 นาที/คน/รอบ) + งาน simulator ให้ทำระหว่างรอคิว (คือ station rotation ในรูปแบบทางไกล)

### 1.6 ความปลอดภัยเมื่อคุมเครื่องจริงทางไกล (Remote Operation Safety)

การให้ผู้เรียนสั่ง servo/robot/เครื่องจริงจากทางไกล = ความเสี่ยงใหม่ที่ต้องคุมเป็นระบบ:

- **ไม่มีคนอยู่ในระยะอันตรายของ rig เสมอ** — rig ที่เปิดรีโมตต้องอยู่ในกรง/กั้น มีเฉพาะ TA ที่ได้รับมอบหมายเข้าใกล้ได้
- **Remote E-stop + Local E-stop** — TA หน้างานกดหยุดได้ทันที + ระบบมี software watchdog ตัดเป็น safe-state เมื่อขาดการเชื่อมต่อ
- **Speed/torque limit บังคับ** — servo/robot ที่เปิดรีโมตล็อกความเร็ว/แรงบิดต่ำ (robot คงโหมด T1 ≤250 mm/s)
- **จำกัดสิทธิ์** — ผู้เรียนสั่งได้เฉพาะ rig ที่จองในรอบของตน ครั้งละ 1 คน มี TA ยืนยันก่อน energize
- **กล้อง + interlock** — ถ้ากล้อง/สัญญาณหลุด ระบบไม่รับคำสั่งเดินเครื่อง
- **Log ทุก session** — บันทึกว่าใครสั่งอะไรเมื่อไร เพื่อสอบสวนเหตุและใช้ประเมินผล

> โมดูลทักษะมือที่มีไฟจริง (M00–M05) **ไม่เปิดให้ทำทางไกล** — ผู้เรียนออนไลน์ทำส่วนทฤษฎี/ออกแบบ แล้วปิดงานมือในโหมด offline/hybrid เท่านั้น

## 2. สัดส่วนทฤษฎี : ปฏิบัติ (Theory : Practice Ratio)

### 2.1 หลักทั่วทั้งหลักสูตร
- **เป้าหมายรวม ≈ ทฤษฎี 30% : ปฏิบัติ 70%** (เน้นปฏิบัติตามโจทย์ "ผู้เชี่ยวชาญที่ทำงานจริงได้")
- "ทฤษฎี" ในที่นี้รวม: บรรยาย, อ่าน datasheet/manual, ออกแบบบนกระดาษ/simulator, วาง I/O list
- "ปฏิบัติ" คือ: ต่อสายจริง, เขียนโปรแกรมจริง, วัด/ทดสอบ, troubleshoot, commissioning

### 2.2 สัดส่วนแยกตามลักษณะโมดูล

| โมดูล | ลักษณะ | ทฤษฎี : ปฏิบัติ | หมายเหตุการจัด |
|---|---|---|---|
| M00 Safety & Fundamentals | พื้นฐาน + safety | 40 : 60 | ทฤษฎีจำเป็น แต่ LOTO/PPE/วัดต้องลงมือ |
| M01 Wiring & Panel | ทักษะมือ | 20 : 80 | เน้นปอก/ย้ำ/จัดสาย/อ่านแบบ ซ้ำจนชิน |
| M02 Relay Logic | ออกแบบ + ต่อ | 30 : 70 | ออกแบบบนกระดาษ → ต่อในตู้จริง |
| M03 Pneumatics | ต่อวงจรลม | 30 : 70 | FluidSIM ก่อน → ต่อจริง |
| M04 Sensors & Actuators | วัด/ต่อ I/O | 30 : 70 | NPN/PNP ต้องพิสูจน์ด้วยมิเตอร์เอง |
| M05 Motor Control | ต่อวงจรกำลัง | 30 : 70 | DOL/Star-Delta/VFD ต่อจริงในตู้ |

## 5. การจัดห้องแล็บและสถานีฝึก (Lab & Station Layout)

### 5.1 โซนในห้องแล็บ
- **โซนบรรยาย (Theory zone):** จอ projector, ไวท์บอร์ด, ที่นั่งหันหน้าผู้สอน — ใช้ช่วงสั้น ๆ
- **โซนสถานีฝึก (Workstation zone):** โต๊ะฝึก/ตู้ฝึก 1–2 คน/สถานี มีไฟ 24VDC + แหล่งจ่าย, รางเก็บเครื่องมือ
- **โซน Robot cell (M09/M12):** กั้น safety fence / light curtain, E-stop ภายนอก, พื้นที่ปลอดคนระหว่าง robot ทำงาน — **เข้าถึงจำกัด**
- **โซนเครื่องมือ/วัสดุกลาง (Tool crib):** มิเตอร์, megger, crimp tool, ferrule, สายตัวอย่าง — มีระบบยืม-คืน
- **โซนความปลอดภัย/ปฐมพยาบาล:** lockout station, ชุด LOTO ส่วนกลาง, CPR manikin/AED trainer, ชุดปฐมพยาบาล, ถังดับเพลิง, ป้ายขั้นตอน

### 5.2 มาตรฐานสถานีฝึก (ต่อสถานี wiring/PLC)
- โต๊ะ/แผงฝึก + DIN rail + wire duct + terminal block
- แหล่งจ่าย 24VDC + เบรกเกอร์/ฟิวส์ + ground/PE bar
- มิเตอร์ดิจิทัล (CAT III ขึ้นไป) 1 ตัว/สถานี + two-pole voltage tester
- ชุดเครื่องมือมือ (stripper, ratchet crimper, ferrule crimper, ไขควง insulated, torque screwdriver)
- ผ้ายางปูพื้นสำหรับงาน live test, แสงสว่างเพียงพอ, ปลั๊กกราวด์ครบ

### 5.3 Checklist เปิด/ปิดห้องแล็บประจำวัน

**ก่อนเริ่ม (ผู้สอน/TA):**
- [ ] เบรกเกอร์เมนปิด, จ่ายไฟทีละโซนตามต้องการ
- [ ] ชุด LOTO ครบจำนวน, padlock/tag พร้อม
- [ ] PPE พร้อมและสภาพดี (ถุงมือฉนวนทำ air/visual test)
- [ ] มิเตอร์ทำงาน + ทดสอบ live-dead-live กับแหล่งที่รู้ว่ามีไฟ
- [ ] Robot cell: safety fence ปิด, E-stop ทดสอบ, light curtain ทำงาน
- [ ] แหล่งลม: ความดันปกติ, valve lockout พร้อม

**ก่อนเลิก:**
- [ ] LOTO ปลดครบ, ตู้ปิดไฟ, depressurize ระบบลม (ความดัน = 0 ยืนยันด้วยเกจ)
- [ ] เครื่องมือคืน tool crib ครบ, นับมิเตอร์/megger
- [ ] Robot กลับ home/safe position, ปิด controller ตามขั้นตอน
- [ ] รายงาน fault/อุปกรณ์เสียหายให้ผู้ดูแลแล็บ

### 5.4 การแก้ปัญหาคอขวดฮาร์ดแวร์ (Hardware bottleneck)
- **Simulator-first:** ให้ออกแบบ/เขียน/ทดสอบบน GX/GT Simulator3 หรือ FluidSIM ก่อน แล้วค่อยขึ้น hardware → ลดเวลารอเครื่อง
- **Station rotation:** แบ่งกลุ่มหมุนเวียนสถานีที่มีของแพง (KUKA, servo slide) พร้อมใบงานคู่ขนานให้กลุ่มที่รอ
- **Fault-injection drills:** ผู้สอนแอบใส่ fault ในตู้ฝึก ให้ผู้เรียนหมุนเวียน troubleshoot — ใช้ของจำกัดให้คุ้ม
- **Pair programming/wiring:** จับคู่ "ทำ + ตรวจ" สลับบทบาท ลดข้อผิดพลาดและเพิ่มการเรียนรู้
- **Remote Lab เป็นตัวคูณการใช้เครื่อง:** rig ราคาแพง (servo, KUKA, P&P) เปิดให้ผู้เรียนออนไลน์ **จองใช้นอกเวลาสอน** ได้ด้วย → เครื่อง 1 ชุดบริการได้ทั้งคลาส on-site (กลางวัน) + ผู้เรียนออนไลน์ (เย็น/ดึก) เพิ่ม utilization ของสินทรัพย์ก้อนใหญ่ที่สุด

### 5.5 การจัด Remote Lab Rig (สำหรับบริการออนไลน์)

- **จัด rig ให้ "รีโมตได้จริง":** ทุก rig ที่เปิดออนไลน์ต้องมี PC/gateway ต่ออยู่ถาวร (รัน GX Works3/GT Designer3), กล้อง 2–3 มุม, และวงจร safety สำหรับคุมทางไกล (ดู §1.6 และ A หมวด Remote Lab)
- **แยกโซน "รีโมต" ออกจากโซนสอนสด:** rig ที่เปิดรีโมตควรอยู่ในพื้นที่กั้น/กรง ที่ TA เห็นได้ตลอด ไม่ปนกับสถานีที่ผู้เรียน on-site เดินไปมา
- **ตารางเครื่อง (rig calendar):** กันเวลา rig เป็นบล็อก — กลางวันใช้สอน on-site, ช่วงเย็น/สุดสัปดาห์เปิดให้จองออนไลน์ + กันเวลา maintenance/backup
- **Fail-safe การเชื่อมต่อ:** เน็ตหลุด/กล้องดับ → PLC ต้องเข้าสถานะปลอดภัย (หยุดแกน) อัตโนมัติ ไม่ค้างเดินเครื่อง

## 6. เทคนิคสอนคน "ไม่มีพื้นฐานเลย" (Teaching Absolute Beginners)

### 6.1 หลักการ
1. **เริ่มจากของจับต้องได้ ไม่ใช่สูตร** — ให้เห็น/แตะ contactor, สาย, sensor ก่อนอธิบายทฤษฎี
2. **คำศัพท์ทีละคำ + อภิธานศัพท์** — แจก glossary ไทย-อังกฤษ (PLC, ladder, NPN, ferrule ฯลฯ) ติดผนัง/แจกการ์ด
3. **Analogy ใกล้ตัว** — กระแสไฟ = น้ำในท่อ (V=ความดัน, I=ปริมาณ, R=ความคับท่อ); PLC scan cycle = อ่านโพย→ทำ→ส่งออก วนซ้ำ
4. **Chunking** — ซอยงานใหญ่เป็นสเต็ปเล็ก ทำทีละสเต็ป ตรวจทีละสเต็ป (โดยเฉพาะ wiring/programming)
5. **Worked example → Guided → Independent** — สาธิตเต็ม → ทำพร้อมกันแบบมีไกด์ → ทำเองโดยมีใบงาน
6. **อนุญาตให้ "พังอย่างปลอดภัย"** — ออกแบบ lab ให้ลองผิดได้โดยไม่อันตราย/ไม่เสียของแพง (simulator, แรงดันต่ำ, fuse ป้องกัน)

### 6.2 เทคนิคในห้อง
- **Demo-along:** ผู้สอนทำบนจอ/สถานีสาธิต ผู้เรียนทำตามทันทีทีละสเต็ป (ห้ามล้ำหน้า)
- **Checkpoint sign-off:** กำหนดจุดตรวจ เช่น "ก่อนจ่ายไฟ ครูต้องเซ็น" — กันอุบัติเหตุ + บังคับให้ทำถูกขั้นตอน
- **Think-aloud troubleshooting:** ผู้สอนพูดออกเสียงตอนไล่หา fault ให้ผู้เรียนเห็น "วิธีคิด" ไม่ใช่แค่คำตอบ
- **One-page job sheet:** ทุก lab มีใบงาน 1 หน้า: เป้าหมาย, อุปกรณ์, ขั้นตอน, checklist ความปลอดภัย, เกณฑ์ผ่าน
- **Visual aids:** โปสเตอร์ LOTO, ชาร์ตรหัสสีสาย, การ์ด NPN/PNP, แผ่นสัญลักษณ์ IEC ติดที่สถานี
- **บันทึก/ถ่ายรูปงานตัวเอง:** ให้ผู้เรียนถ่ายรูปการต่อสายที่ถูกต้องไว้เป็น reference ของตัวเอง

### 6.3 จัดการความกลัว (โดยเฉพาะงานไฟ/robot)
- เริ่มงานไฟด้วย **24VDC ปลอดภัยก่อน** แล้วค่อยขยับสู่แรงดันสูงเมื่อมั่นใจขั้นตอน
- ย้ำว่า "ความปลอดภัย = ขั้นตอน ไม่ใช่ความกล้า" — ทำตาม checklist ทุกครั้งคือถูก
- robot: เริ่มที่ T1 (จำกัด 250 mm/s) + override ต่ำ + อธิบาย enabling switch 3 ตำแหน่งก่อนแตะ smartPAD

## 7. การจัดการผู้เรียนต่างระดับ (Mixed-Ability Management)

### 7.1 ประเมินก่อนเรียน (Pre-assessment)
- ทำแบบทดสอบสั้น + สัมภาษณ์: เคยจับเครื่องมือ/อ่านแบบ/เขียนโปรแกรมไหม
- จัดกลุ่มเริ่มต้น: **มือใหม่จริง / มีพื้นฐานช่างไฟ / มีพื้นฐานโปรแกรม** เพื่อวางคู่และความคาดหวัง

### 7.2 กลยุทธ์ระหว่างเรียน

| สถานการณ์ | กลยุทธ์ |
|---|---|
| คนเร็ว vs คนช้าในคลาสเดียว | **Tiered tasks:** ใบงานมี "core (ทุกคนต้องทำ) + stretch/bonus (คนเร็วทำต่อ)" |
| คนเร็วเสร็จก่อน | ให้เป็น **peer mentor** ช่วยเพื่อน (See it–Do it–Teach it) หรือทำโจทย์ขั้นสูง/fault-injection |
| คนช้า/ตามไม่ทัน | TA ประกบ, ลดสเต็ป, ให้เวลาเสริมนอกคลาส, ใช้ simulator ฝึกซ้ำ |
| พื้นฐานต่างกันมาก | **จับคู่ heterogeneous** (เก่ง+อ่อน) แต่สลับบทบาท "ทำ/ตรวจ" เพื่อไม่ให้คนอ่อนเป็นผู้ดูอย่างเดียว |
| มีพื้นฐานบางส่วนแล้ว | ให้ **test-out** บางหัวข้อด้วยการสาธิตทักษะ (เช่น crimp ผ่าน pull test) แล้วขยับไป stretch task |

### 7.3 กฎ "ไม่ทิ้งใครไว้ข้างหลัง" บนงานที่มีความปลอดภัยสูง
- **ทุกคนต้องผ่าน gate ความปลอดภัยก่อนเสมอ** — ห้าม fast-track ข้าม LOTO / pre-power-on check ไม่ว่าจะเก่งแค่ไหน
- ใช้ **competency checklist รายคน** (ดูข้อ 8) เป็นเกณฑ์ผ่านจริง ไม่ใช่แค่ "ทำเสร็จ"

### 7.4 จังหวะคลาส (Pacing)
- วางบัฟเฟอร์เวลา ~10–15% ในแต่ละโมดูลสำหรับคนช้า/แก้ปัญหาหน้างาน
- ใช้ "exit ticket" ท้ายวัน (คำถาม 2–3 ข้อ) เช็คว่าใครยังไม่เข้าใจ เพื่อปรับวันถัดไป

## 8. การประเมินและเกณฑ์ผ่าน (Assessment — สรุปสำหรับผู้สอน)

### 8.1 หลักการประเมิน
- **Competency-based:** วัดที่ "ทำได้จริง" ตาม objective ของแต่ละโมดูล ไม่ใช่ข้อสอบกระดาษอย่างเดียว
- สัดส่วนแนะนำ: **ปฏิบัติ/competency 70% : ความรู้/quiz 20% : ความปลอดภัย/วินัย 10%** (ความปลอดภัยเป็น gate — ละเมิดร้ายแรง = ไม่ผ่านทันที)

### 8.2 เครื่องมือประเมิน
- **Competency checklist รายโมดูล** (เช่น "ต่อ NPN/PNP เข้า FX5U ถูกต้องและปลอดภัย: ผ่าน/ไม่ผ่าน")
- **Practical exam:** ต่อวงจร/เขียนโปรแกรม/commission ตามโจทย์ภายในเวลา
- **Troubleshooting drill:** หา + แก้ fault ที่ผู้สอนแอบใส่
- **Capstone (M12):** ส่งมอบเอกสาร (I/O list, SOO, safety concept) + เครื่องทำงานได้จริง + นำเสนอ

### 8.3 เกณฑ์ "ผ่านเพื่อขึ้นโมดูลที่มีไฟ/การเคลื่อนที่"
- [ ] ทำ LOTO + live-dead-live ได้ถูกทุกสเต็ป
- [ ] เลือก/สวม PPE ถูก + ตรวจถุงมือฉนวนได้
- [ ] ทำ pre-power-on checklist ครบก่อนจ่ายไฟ
- [ ] ได้รับ sign-off จากผู้สอนก่อน energize ครั้งแรก

### 8.4 การประเมินในโหมดออนไลน์ (Online Assessment)

- **โมดูลโปรแกรม (M06/M07/M11/M13) ประเมินออนไลน์ได้เต็มรูปแบบ:** ให้ผู้เรียน download โปรแกรมลง **PLC/GOT จริงผ่าน Remote Lab** แล้วสาธิต sequence/แก้ fault ให้ดูสด (แชร์จอ + กล้อง) — วัด "ทำได้จริงบนเครื่องจริง" ไม่ใช่แค่ simulator
- **Practical exam ผ่านกล้อง:** ผู้เรียนเปิดกล้อง + แชร์จอ ทำโจทย์ในเวลาที่กำหนด ผู้สอน inject fault ทางไกลสำหรับ troubleshooting drill
- **Proctoring / กันโกง:** เปิดกล้อง, แชร์ทั้งจอ, ล็อกอิน Remote Lab รายบุคคล, log ทุกคำสั่ง (ดู §1.6) เพื่อยืนยันว่าเป็นฝีมือผู้เรียนเอง
- **ทักษะมือประเมินออนไลน์ไม่ได้ (gate ต้องทำ on-site):** LOTO, live-dead-live, crimp/pull test, ประกอบตู้, ต่อ wiring servo/robot — ผู้เรียนออนไลน์ **ต้องมาสอบ gate เหล่านี้แบบ on-site (โหมด ②/④)** ก่อนได้รับการรับรองระดับที่เกี่ยวข้อง
- **Capstone (M12):** ส่วน logic/integration ทำ+สาธิตผ่าน Remote Lab ได้ แต่ **การประกอบเครื่อง + commission ไฟจริง ต้องทำ on-site** เพื่อให้ผ่านเกณฑ์ครบ

> **กฎการรับรอง:** ใบรับรองที่อ้าง "ทักษะมือ/งานไฟ" จะออกให้ก็ต่อเมื่อผู้เรียนผ่าน **gate on-site** แล้วเท่านั้น — ผู้เรียนออนไลน์ล้วนที่ยังไม่ผ่าน gate มือ ได้เฉพาะการรับรอง "ภาคโปรแกรม/ทฤษฎี" (สอดคล้องกับระบบรับรองในเอกสาร E)

## 9. สรุปสำหรับผู้สอน (Quick Reference)

| ประเด็น | ค่าที่แนะนำ |
|---|---|
| รูปแบบหลัก | **Online + Remote Lab เป็นแกน** (+ Offline พรีเมียมสำหรับทักษะมือ + On-site ต่างจังหวัด/corporate + Hybrid) |
| Remote Lab | เครื่องจริง (PLC/HMI/servo/robot) ต่อทางไกล + กล้องหลายมุม — **ฟรีสำหรับผู้เรียน** |
| โมดูลออนไลน์ได้ 100% | M06, M07, M11, M13 (เขียนโปรแกรม) |
| โมดูลต้อง on-site | M00–M05 + งาน wiring ใน M08/M09/M12 (ทักษะมือ/งานไฟ) |
| ทฤษฎี : ปฏิบัติ (รวม) | ~30 : 70 |
| ขนาดคลาส | Offline 8–12 คน · Online 8–16 คน (เพดาน + ผู้ช่วย) |
| ผู้เรียน/สถานี | 1–2 คน (robot 2–3 คน/cell) |
| Instructor : learner | Offline 1 : 6 (งานไฟ/servo/robot 1 : 4–6 + TA) · Online 1 : 8–12 + TA |
| ชั่วโมงรวม Core / +Elective | 464 / 496 ชม. |
| ระยะ full-time Core | ~16 สัปดาห์ (~4 เดือน) |
| บรรยายต่อเนื่องสูงสุด | 20–25 นาที ก่อนสลับกิจกรรมมือ/Remote Lab |
| กฎเหล็ก | Safety gate ก่อนทุก lab มีไฟ + sign-off ก่อน energize + **TA หน้า rig เสมอเมื่อคุมเครื่องทางไกล** |
